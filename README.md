# Abdul Rahman Jami — Portfolio

Static 4-page developer portfolio for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About / Experience / Education
- `projects.html` — Selected projects with filters and screenshot previews
- `certifications.html` — Certificates, current learning and contact

## Deploy with GitHub Pages
1. Create a public GitHub repository, e.g. `abdulrahman-jami-portfolio`.
2. Copy all files from this ZIP into the repository root. `index.html` is already at the repository root.
3. Commit and push to `main`.
4. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
5. Open the generated GitHub Pages URL.
